게임 툴팁 스캔

GMS 영어 툴팁

  1. 게임 창 공유를 누르고 MapleStory 창을 고르세요.
  2. 자동 스캔 시작을 누르고 게임으로 돌아가세요.
  3. 장비에 마우스를 2~3초 올려 두면 읽고 판정해요. 딩동 = 남김, 삐삐 = 분해.

이 페이지를 클릭한 상태에서 F2 = 한 번 캡처, F3 = 방금 추가한 장비 취소. 스크린샷을 붙여넣어도 돼요.

스캔 설정
이 스킬이 하나라도 있으면 스킬 장비로 안 씀 (소켓 장비 판정은 그대로):
소켓 3개가 모두 이 색이면 남김:

이미지를 붙여넣어도 됩니다. 처음 인식할 때 인터넷이 필요합니다.

스캔 기록
    인벤토리 O/X 표시 인벤토리를 한 번 찍어 두면 스캔한 장비 칸에 남김/분해가 표시돼요

    장비 칸 영역(맨 왼쪽 위 칸의 왼쪽 위 모서리 ~ 맨 오른쪽 아래 칸의 오른쪽 아래 모서리)을 드래그하고, 가로·세로 칸 수를 맞춰 격자가 칸과 겹치면 저장하세요. 찍을 때 마우스는 인벤토리 밖에 두세요.

    O = 남김 · X = 분해 · ? = 소켓 확인 필요. 칸을 클릭하면 O → X → 비움 순으로 바꿀 수 있어요.

    인식이 잘 안 되면 이미지에서 왼쪽 툴팁만 드래그한 뒤 다시 읽으세요.

    최적 소켓 조합 
    

    공략 기준: 흰색(무지개)+2색 4부위 · 3색 2부위. 한 장비 안에서는 색을 섞을수록 좋아요(빨빨빨보다 빨검초). 스킬은 같은 부위 소켓 장비로 전승되므로 소켓 장비의 스킬 줄은 상관없고, 소켓 장비는 내 주 스탯을 쓰는 직업군 장비여야 해요(STR 전사·해적, DEX 궁수·해적, INT 마법사, LUK 도적). 자동 스캔 때 조건에 맞는 소켓 장비는 여기에 자동으로 들어와요.
