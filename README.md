# 리베 장비 계산기

메이플스토리(GMS) 콰나 서버의 **Libae's Supercharged** 장비용 계산기입니다.

- 게임 창을 공유하면 장비 툴팁을 자동으로 읽어서(OCR) 장비를 등록합니다.
- 보유 장비 중에서 **18줄 스킬 조합**과 **소켓 조합**(흰색+2색 4부위 · 3색 2부위)을 계산합니다.
- 인벤토리에 남길 장비(O)와 분해할 장비(X)를 표시합니다.

**바로 쓰기:** https://naru-jin.github.io/libae-solver/

장비 목록은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다. 크롬이나 엣지에서 사용하세요.

## 참고

- 18줄 조합 계산은 [3L Set Solver](https://freehtmlhost.com/3l-set-solver/)를 바탕으로 만들었습니다.
- 소켓 기준은 GMS 히로익 마이너 갤러리의 콰나 서버 공략을 참고했습니다.
- 글자 인식: [Tesseract.js](https://github.com/naptha/tesseract.js) · 글꼴: [Pretendard](https://github.com/orioncactus/pretendard)
